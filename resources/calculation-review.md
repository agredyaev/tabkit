# Calculation review
Inspect internal field identifiers and formulas before proposing edits. Check null handling, division by zero, aggregation level, joins/duplication, parameter types, date bounds and dependencies. Do not automatically equate SUM(Profit)/SUM(Sales) with SUM(Profit/Sales). Preserve the user's intended grain. Local token/reference checks do NOT type-check or execute Tableau formulas. Use Hyper only for independently stated extract SQL controls; do not claim that it evaluated a workbook calculation. Emit changes through set_calculation in a changeset; policy must explicitly permit unverified-formula candidates. Verify the candidate in the user's Tableau 2025 environment before relying on its result.
