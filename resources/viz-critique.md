# Visualization critique
Review an actual PNG from tableau_view_image, not a guessed dashboard. Discuss encoding suitability, axes/units, legends, visual hierarchy, label legibility, visible filter state and consistency. Separate observations, likely issues and unverified behavior. A static image cannot prove tooltip behavior, keyboard access, filter action correctness, responsiveness or calculations. Read-only review does not authorize edits or publishing. Use a short finding format: evidence, consequence, proposed change, verification. Unsupported layout changes remain recommendations.
