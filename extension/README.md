# TabKit Web Dashboard extension

This directory contains the browser runtime embedded by tabkit-extension-host and the development TREX manifest.

## Production

Use the dedicated binary from CI or a GitHub release:

    tabkit-extension-host-v0.9.0-linux-x64.zip
    tabkit-extension-host-v0.9.0-windows-x64.zip

The binary embeds:

    host.html
    host.css
    host.js
    vendor/tableau.extensions.1.17.0.min.js

Production bundles are signed. Configure the same base64 32-byte TABKIT_EXTENSION_SIGNING_KEY on the TabKit authoring process and on tabkit-extension-host.

Example:

    tabkit-extension-host --bind 127.0.0.1:8765 --base-path /tabkit

Put HTTPS in front of the listener and safe-list the exact public URL in Tableau Server.

See ../docs/EXTENSION_DEPLOYMENT.md for the full deployment procedure.

## Development

Unsigned execution is allowed only when the browser sees a loopback hostname.

Serve this directory on localhost:

    python -m http.server 8765 --directory extension

Add tabkit-web-dashboard.trex to Tableau. The development manifest points to:

    http://localhost:8765/host.html

## Runtime contract

TabKit stores:

- tabkit.bundle_b64
- tabkit.bundle_mac

The decoded UTF-8 JSON bundle contains runtime_version, html, css, and javascript. Runtime version 1 is current. The public host URL remains stable across compatible runtime revisions.

Generated JavaScript receives a narrow window.tabkit API:

- listDataSources()
- listLogicalTables(datasource)
- getLogicalTableData(datasource, table, maxRows?)
- listWorksheets()
- getSummaryData(worksheet, maxRows?)
- applyFilter(worksheet, field, values)
- clearFilter(worksheet, field)
- listParameters()
- setParameter(name, value)
- on(event, handler)

The child cannot access tableau.extensions directly. Data and summary reads are capped by row and byte limits, bridge concurrency is bounded, and production bundles must pass server-side signature verification before execution.

The iframe sandbox and CSP are defense in depth. They are not the trust root for arbitrary JavaScript. The production trust root is the signed bundle generated by the trusted TabKit authoring path.

## Vendored dependency

vendor/tableau.extensions.1.17.0.min.js is taken from the official tableau/extensions-api v1.17.0 release tag. The upstream Apache-2.0 license is retained as vendor/LICENSE-tableau-extensions-api.txt.
